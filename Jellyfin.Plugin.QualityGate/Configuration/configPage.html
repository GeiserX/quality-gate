Version Grouping

Jellyfin only groups alternate versions inside a folder named after the film. In a library whose films sit loose at the root, an encoded copy placed beside its original therefore shows up as a second film. Turn this on to group the two wherever they sit, so viewers see one film with a version picker.

Changing this changes how a library resolves. Run a library scan afterwards, and expect the copies to disappear from the film list as they join their originals.
